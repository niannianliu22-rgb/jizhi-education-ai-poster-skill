# QA Checklist

## Brand isolation

- One brand promise system per poster.
- No DP guarantee language in 极致 Essay or 极致 AI 留学生陪跑.
- No generic visual system that erases brand differences.
- DP chest mark only for DP; AI chest mark only for 极致 AI 留学生陪跑.
- Only user-confirmed IP assets for the active brand.

## Product truth

- No invented services, features, prices, discounts, guarantees, or refund terms.
- Every number and promise is traceable to source material.
- Inferred copy is labeled and remains low-risk.

## Original materials

- Original logos only.
- No AI-generated or redrawn logos.
- No rewritten grades, screenshots, customer feedback, or chat UI.
- Case evidence remains the original image with original aspect ratio and readable content.
- Only placement-level scaling, framing, border, shadow, spacing, stacking, and positioning are allowed.
- If privacy is visible, request an already-redacted original.

## Canvas sizing

- Height follows content amount and evidence count.
- A case poster is not automatically a long image.
- No clipped content, crowded endings, excessive empty space, or unreadably small evidence.

## CTA

- No CTA by default for any brand or poster.
- No reservation buttons, QR prompts, contact prompts, keyword prompts, or conversion footer unless explicitly requested.

## Prompt modules

1. Task definition
2. Canvas
3. Brand visual
4. Composition and layout
5. Image elements
6. Text plan
7. Original-material placement plan
8. Negative constraints

## Blocking conditions

Return `不通过` for:

- Fabricated product facts
- Fake or modified case evidence
- AI-generated logo
- Cross-brand IP substitution
- Privacy leakage
- Unsupported promises
- Forced fixed-height layout that makes evidence unreadable
